Question 253

Create a Java program to access the java.util.Date class through qualified way and print the current date of the system but inherit the Date class.

Solution

package packages;
public class Q253 {
    static class MyDate extends java.util.Date {
        void show(){
            System.out.println("MyDate says: "+this);
        }
    }
    public static void main(String[] args) {
        MyDate d = new MyDate();
        d.show();
    }
}
