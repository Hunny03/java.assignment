Question 219

Write a Java method to compute the average of three numbers

Solution

package basics;
public class Q219 {
    static double avg3(double a, double b, double c){
        return (a+b+c)/3;
    }
    public static void main(String[] args) {
        System.out.println("Average of 12, 18, and 27 = "+avg3(12,18,27));
    }
}
