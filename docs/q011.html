Question 011

Program to print the number of elements present in an array

Solution

package singlearrays;
public class Q011 {
    public static void main(String[] args) {
        String a[] = {"Tanya","Rohit","Meera","Aman","Sana"};
        System.out.println("Number of array elements = "+a.length);
    }
}
