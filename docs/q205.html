Question 205

Write a java program to print numbers from 1 to 10 using loop

Solution

package basics;
public class Q205 {
    public static void main(String[] args) {
        for(int i=1;i<=10;i++)
            System.out.print(i+" ");
        System.out.println();
    }
}
