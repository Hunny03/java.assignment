Question 260

Write a Java program to create a class called Animal with a method called makeSound(). Create a subclass called Cat that overrides the makeSound() method to bark.

Solution

package inheritance;
public class Q260 {
    static class Animal {
        void makeSound(){ System.out.println("The animal makes a sound"); }
    }
    static class Cat extends Animal {
        void makeSound(){ System.out.println("The cat is barking (as stated in the question)"); }
    }
    public static void main(String[] args) {
        Animal a = new Animal();
        Cat c = new Cat();
        a.makeSound();
        c.makeSound();
    }
}
