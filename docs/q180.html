Question 180

Write a java program to count total number of lines from a string

Solution

package basics;
public class Q180 {
    public static void main(String[] args) {
        String s = "First line\nSecond line\nThird line\nFourth line";
        String l[] = s.split("\n");
        System.out.println("Total lines = "+l.length);
    }
}
