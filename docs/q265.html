Question 265

Write a Java program to create a class called Animal with a method named move(). Create a subclass called Cheetah that overrides the move() method to run.

Solution

package inheritance;
public class Q265 {
    static class Animal {
        void move(){ System.out.println("The animal moves"); }
    }
    static class Cheetah extends Animal {
        void move(){ System.out.println("The cheetah runs at 100 km/h"); }
    }
    public static void main(String[] args) {
        Animal a = new Cheetah();      // parent ka reference, child ka object
        a.move();
    }
}
