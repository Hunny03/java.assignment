Question 223

Write a Java method to compute the sum of the digits in an integer

Solution

package basics;
public class Q223 {
    static int total(int n){
        int s = 0;
        while(n>0){
            s += n%10;
            n /= 10;
        }
        return s;
    }
    public static void main(String[] args) {
        System.out.println("Sum of the digits of 90817 = "+total(90817));
    }
}
