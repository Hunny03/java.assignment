Question 033

Write a Java method to count the number of digits in an integer with the value 2. The integer may be assumed to be non-negative.

Solution

package functions;
public class Q033 {
    static int dogin(int n){
        int c = 0;
        while(n>0){
            if(n%10==2) c++;
            n = n/10;
        }
        return c;
    }
    public static void main(String[] args) {
        System.out.println("Count of digit 2 in 2202 = "+dogin(2202));
        System.out.println("Count of digit 2 in 135 = "+dogin(135));
        System.out.println("Count of digit 2 in 222222 = "+dogin(222222));
    }
}
