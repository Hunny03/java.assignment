Question 251

Create a Java program to access the java.util.Date class through qualified way and print the current date of the system.

Solution

package packages;
public class Q251 {
    public static void main(String[] args) {
        // import nahi kiya isliye poora naam likha java.util.Date
        java.util.Date d = new java.util.Date();
        System.out.println("Current system date = "+d);
    }
}
