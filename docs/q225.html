Question 225

Write a Java method to calculate the area of a triangle

Solution

package basics;
public class Q225 {
    static double triArea(double b, double h){
        return 0.5*b*h;
    }
    public static void main(String[] args) {
        System.out.println("Area = "+triArea(9,14));
    }
}
