Question 029

Write a Java method to print characters between two characters (i.e. A to P).

Solution

package functions;
public class Q029 {
    static void dikha(char a, char b){
        for(char c=a;c<=b;c++)
            System.out.print(c+" ");
        System.out.println();
    }
    public static void main(String[] args) {
        dikha('A','P');
    }
}
