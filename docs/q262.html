Question 262

Write a Java program to create a class called Shape with a method called getArea(). Create a subclass called Rectangle that overrides the getArea() method to calculate the area of a rectangle.

Solution

package inheritance;
public class Q262 {
    static class Shape {
        double getArea(){ return 0; }
    }
    static class Rectangle extends Shape {
        double l, b;
        Rectangle(double l, double b){ this.l=l; this.b=b; }
        double getArea(){ return l*b; }
    }
    public static void main(String[] args) {
        Shape s = new Shape();
        Shape r = new Rectangle(12,7);
        System.out.println("Shape area = "+s.getArea());
        System.out.println("Rectangle area = "+r.getArea());
    }
}
