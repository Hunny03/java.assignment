Question 250

Create a Java program to access the java.util.Date class through import keyword and print the current date of the system.

Solution

package packages;
import java.util.Date;      // import se sirf Date likhna padta hai
public class Q250 {
    public static void main(String[] args) {
        Date d = new Date();
        System.out.println("Current system date = "+d);
    }
}
